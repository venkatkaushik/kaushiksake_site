# kaushiksake.com — personal site

Single-file, zero-dependency personal website. Dark theme, no build step, no frameworks.

## Features
- UI language switcher across 9 languages (English, Русский, हिन्दी, తెలుగు, ಕನ್ನಡ, தமிழ், മലയാളം, অসমীয়া, संस्कृतम्) with persistence
- Career observability dashboard — metrics cards, first-principles process tree ([ kernel ] → PID 1 → skills), deployment log
- Clickable skill deep-dives: work, impact, and "did you know" panels for 8 domains
- Purpose section — the kernel statement with receipts
- Conlang section (Thicchippi & Dekkitansna) — explorer coming soon
- Accessible: keyboard focus rings, reduced-motion support, lang-attribute switching

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Site appears at `https://<username>.github.io/<repo>/`
- **Vercel:** vercel.com → New Project → import this repo → Deploy. No configuration needed.

## Local preview
Just open `index.html` in any browser. No server required.
